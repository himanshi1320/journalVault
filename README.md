# JournalVault – Secure Journal Management Platform

## Overview

JournalVault is a backend application built using Spring Boot and MongoDB that enables users to securely create, manage, and organize personal journal entries.

## Features

* User Authentication and Authorization
* Journal CRUD Operations
* Role-Based Access Control
* MongoDB Integration
* Centralized Logging with Logback
* Unit Testing with JUnit 5 and Mockito

## Tech Stack

* Java
* Spring Boot
* Spring Security
* MongoDB
* Spring Data MongoDB
* JUnit 5
* Mockito
* Logback
* Maven

## Architecture

Controller → Service → Repository → MongoDB

## Key Implementations

* Secure access management using Spring Security and BCrypt password encryption.
* Document-oriented data modeling with MongoDB and Spring Data.
* Structured logging and monitoring through Logback.
* Automated unit and integration testing using JUnit 5 and Mockito.
